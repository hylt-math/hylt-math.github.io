## 2. 確認した項目（誤りなし）

- 主シンボル: 公式 (7.1) と不変性の証明、合成と随伴、Poisson 括弧の問（符号 $-i\{\cdot,\cdot\}$ を再計算）、Laplacian・$d$・$\bar\partial$・Dirac 型のシンボル。$|\xi^{0,1}|^2=\frac12|\xi|^2$。
- 楕円複体: Prop cxequiv の 3 条件の同値、フィルトレーション補題の証明、統合論文の全複体 $D=\bar\partial+(-1)^ad_E$ が $D^2=0$ で楕円複体であること。シンボルが $\xi^{0,1}$ と $\sigma^\sharp\xi^{1,0}$ の外積の Koszul 複体になることは論文 §3 の証明 (1) と一致。$v=0$ でも $w\ne0$ なら完全（問 n1total と整合）。
- Euler 標数が $\sigma$、$V$（$E$ 固定）によらない証明（$D_t=\bar\partial+t(-1)^ad_E$ の変形で $t=0$ に帰着）。右辺 $=(-1)^n\mathrm{rk}E\,\chi(X)$ は論文の定理 22、$\CP^n$ で $\sum_b(-1)^b\chi(\wedge^bT(m))=(-1)^n(n+1)$（$n\le6$、$|m|\le8$）を別実装で確認。$\CP^2$ の 1、8、10、和 3。
- トーラスの Sobolev 空間、Peetre の不等式、乗法、Rellich、定数係数の評価、交換子の補題（定数 3 を含む正則化の評価を数値でも確認）、楕円評価（凍結、局所化、交換子、補間の各段で不等式の向きと定数の依存順序が正しい）、楕円正則性（Friedrichs 正則化、$\theta\le1$ の指数の検算）、強楕円型の Gårding と Lax–Milgram。
- Fredholm 理論: Atkinson、六項完全列、安定性（Gauss 消去の分解式を検算）、コンパクト摂動、ホモトピー不変性。
- 閉多様体: Fredholm 性、$\Coker\cong\Ker P^*$、スペクトル定理、Hodge 分解（定理 7.7 に当たる楕円複体の Hodge 分解の (a)〜(d)）、$\chi=\ind(P+P^*)$。
- 指数とシンボル: 低階の摂動、ホモトピー不変性、擬微分作用素の合成公式（torus 上で Taylor 展開から厳密に導かれることを確認）、$A_f$ の指数 $-w$、奇数次元で微分作用素の指数 0（問 S1odd の証明）。
- 例: $S^1$ の $d/d\theta-b$、$T^2$ の $\bar\partial_{L_k}$（接続の整合、曲率、$c_1$、Fourier 分解、核・余核、$k<0$、$k=0$）、Riemann 面の表、Landau 準位の等間隔性（$\frac{k}{4\pi}n$、数値で一致）、非コンパクトの例（Weyl 特異列、$\partial_t+c$、おもちゃの $b$ 模型の 3 場合、Dirichlet 条件つき）。
- Weyl の格子点数（317、3149、31417、4169、132451）。
- 全 40 問: すべて独立に解き直した。解答の誤りはなかった（問題文の不適切な箇所もなかった）。数値は verify3.py で、記号計算は手で確認。
