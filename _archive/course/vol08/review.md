- 余境界の節（§9）の「余境界環の計算」「生成元での確認」の細部、APS の指数公式の符号（第10巻）、族の指数（第9巻）との接続の記述（第9巻の内容は本査読の範囲外）。

## 4. 残る懸念

- **向きの規約は「検算で固定した」ものである。**本巻は $(-1)^{n(n+1)/2}\int_X$ の形に固定しており、4 つの古典定理と $S^1$ で矛盾がないことは確認した。ただし、他書の公式（$(-1)^n\int_{T^*X}$ など）と記号の対応を厳密に取ったわけではない。読者が他書と並べて読むときの注意を、本巻は §5 の注意（符号・向きの規約についての注意）に書いている。
- §8 の Getzler の再スケーリングと Mehler の公式は概念図で、符号つきの細部（上記）が検証されていない。局所指数定理を使う後続の巻（第9巻の Bismut 超接続）がこの節の細部に依存しないことの確認は、第9巻の査読に委ねる。
- 問 landau（Landau 準位）の例のような「符号のうち数値検算で見えにくいもの」（今回の #2）が他にもないか、という懸念は残る。今回は $F$ の符号、$c_1$ の符号、Clifford の $\omega_{\C}$ の符号、$\Delta^\pm$ の名前、$\tau$ の符号をそれぞれ独立に確認したが、全体の網羅は保証できない。
- 第10巻以降（APS・$b$-計算・Lie 亜群、第11〜14巻）は本巻の記述では「次巻以降」の位置づけだが、現時点で未執筆である（学習コースの範囲は第9巻まで）。§11 と §12 の「第10巻」「第13〜14巻の主題」への参照は予定の記述として読む必要がある。公開時に学習地図と整合しているか確認するとよい。
- §10 のコードの記述（`lib8.py`、`verify8.py`）は執筆者の実装で、付録で述べたとおり本査読の `verify9.py` はこれらとは別実装。本査読で `lib8.py`、`verify8.py` に誤りがあるとは見つからなかった（出力は `verify8.out` と `verify9.out` で一致する項目が多数）。
