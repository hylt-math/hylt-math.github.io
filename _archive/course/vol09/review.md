## 2. 確認した項目（誤りなし）

別実装または手計算で独立に確認したもの。

- **符号・向きの規約**
  - Chern 指標・Todd・$\Ahat$、$\Td=\Ahat e^{c_1/2}$、$\Td(-x)=e^{-x}\Td(x)$。
  - Koszul 類の $\ch(\lambda_V)=(-1)^rUe^{c_1}\Td^{-1}$（第8巻 補題と同形）。Bott 類で $\int\ch(\beta)=-1$、第8巻の規格化 $\ind_t(b)=(-1)^N\int\ch b$ と整合。
  - Gysin、$\ch(i_!x)=i_*(\ch x\,\Td(N)^{-1})$、点の Gysin 像 $i_!(1)=[\Oc(1)]-1=[\Oc_p]$。
  - 族の指数定理の形 $(-1)^n\pi_*(\ch\sigma\,\Td(T\otimes\C))$ は第8巻の $B=\mathrm{pt}$ の公式と同形。
  - 指数束 $-[\Oc_p]$（符号は局所模型の単純零点から確定）。Toeplitz 族の $c_1(P_+)=-1$、$\ind A=-[P_+]$、$\ch=-1+x$（解析的に、また別実装の数値で確認）。
- **Atiyah--Jänich・スペクトル流**
  - $\Fred\simeq\Z\times BU$ の $\pi_k$。許容部分空間による指数束の構成と整合性の証明（(1)〜(5) の各段）。
  - $-i\,d/d\theta+f(t)$ の $\sfl=f(1)-f(0)$（整数の横切りを数える議論で一般の $f$ を厳密に）。$\partial_t+A_t$ の核を明示的に解いて $\ind=+1=\sfl$ を確認（写像トーラスの主張の例）。
- **McKean--Singer・Bismut 超接続・Chern--Simons 超越**
  - 階数 $(1,1)$ の超接続を、グレードつきテンソル積の Koszul 符号まで明示して実装（verify9_review.py §8）。$N^2=\mathrm{diag}(-d\bar f\wedge df,+d\bar f\wedge df)$、$\Str e^{-\mathbb A_t^2}=-te^{-t|f|^2}d\bar f\wedge df$、積分は $f=z$ で $-1$、$f=z^2$ で $-2$、$t$ によらない。
  - Chern--Simons 超越の解答（$-d\Str(\dot{\mathbb A}e^{-\mathbb A^2})=\frac d{dt}(-te^{-t|z|^2}d\bar zdz)$）を手計算で確認。命題 CS の証明（Leibniz と $[\mathbb A,e^{-\mathbb A^2}]=0$）。
  - 平坦トーラスの $\Str=0$、$4\pi/t$。Bismut 超接続の形 $\nabla+\sqrt tD-c(T)/4\sqrt t$（BGV と同形。係数は\tQ のまま）。
- **GRR・直像**
  - $\CP(V)\to B$ のファイバー積分 $\pi_*f(h)=\sum f(-a_i)/\prod(a_j-a_i)$、Lagrange 恒等式（$r=2,3,4$、$k=-9,\dots,7$、有理数で厳密に不一致 0）。相対 Serre 双対との整合 $\pi_!\Oc(-2)=-\det V$。
  - $SU(2)$ 束の球面束の Dirac 族 $\sinh(ka)/\sinh a=\ch\Sym^{k-1}V$。
  - Hirzebruch 曲面の $\chi$ を、曲面の HRR（$h^2=-n$）で独立に再計算し、表と一致（$n=1$: $1,1,0,-2,-5$。$n=2$: $1,0,-3,-8,-15$）。
  - Picard 束 $\ch=(d+1-g)-\theta$、$c=e^{-\theta}$。$C\times C$ の GRR で Abel--Jacobi 曲線上の次数 $-g$（解答の途中式を全て確認）。$g=1$ の $d=0,1$ は Mukai 変換の既知の結果と整合。
  - Hodge 束 $c_1(\lambda)=0$、K3 で $\deg\lambda=2$。de Rham 族の $\prod(1-e^{-x})\Td=c_n$。
- **Landau 準位の族**：$k=1,2,3$ で $\bar\partial$ 方程式と準周期性の残差（$10^{-10}$ 以下）。格子法で $c_1=-1$（別実装）。
- **Gauss--Manin・Legendre**：Picard--Fuchs の漸化式（係数を厳密に 58 項）、$M_0M_1$ の跡 $-2$、$(M_0M_1+I)^2=0$、$I_2^*$ 型。
