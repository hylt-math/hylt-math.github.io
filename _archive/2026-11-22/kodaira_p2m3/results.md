# Poisson–Kodaira 予想の P² m=3 での検証（結果ノート）

凡例: [E] 整数/有理数の厳密計算で確認 · [Fp] 有限体 mod p の厳密線形代数 · [N] 浮動小数点の数値計算（証明ではない） · [?] 未確認

## 0. 結論（先に）

1. **m=2（Fermat, P⁵）**: Poisson 拡張が存在する。しかも**整数係数・非零成分 9 個のスパースな厳密解**が見つかり、整数演算で Jacobiator が恒等的に 0 であることを確認した [E]。Round E の「数値的存在」が「厳密な存在」に格上げされた。
2. **m=3（P⁹, 未知数 1215）**: 滑らかな Fermat 3 次曲線、尖点 3 次、結節 3 次のいずれでも、**完全な 2 次方程式 Jacobiator(B₀+ε)=0 の解は見つからなかった**。複数の初期値（スケール 0.1〜33）から、Fermat では毎回同一の最小残差 ‖R‖ = 165.6746（‖J₀‖ = 3123.7 の約 5%）に収束する。複素未知数にしても（未知数 1215 個、複素 LM）同じ点に収束し、虚部は 0。トーリック（xyz）では厳密解が存在する（定理 PK-toric の確認）[N]。
   → **m=3 では予想の結論（Poisson 埋め込み）は成り立たないように見える（数値的反証方向）。ただし mod p の厳密な不可能性証明は得られていない [?]。**
3. 予想そのものの判定: 予想は「ある m₀ があって m ≥ m₀ なら」という主張で、m=3 での失敗は m₀ > 3 を意味するにすぎない。**予想全体は「判定不能」**。m=2 で成り立ち m=3 で（Fermat 等の非トーリックで）成り立たない、という非単調な状況が見えた点が新しい情報。m=4 の制限ansatz（下記）でも解は見つからなかったが、これは完全な検査ではない。
4. 1 次の障害類 J₀ mod im L は、Fermat / Hesse(λ=5) / 尖点 / 結節 のすべてで 0 でない（m=2 でも同様）。m=2 では 1 次障害が 0 でなくても解が存在するので、**1 次の障害は判定に使えない**（2 次の項が本質的）。トーリック xyz では 1 次障害は消える。

「mod p の結果は『計算で確認』であって証明ではない」: 本ノートの mod p の部分は線形代数（L の階数・1 次障害）に限られ、反証・存在証明そのものは数値（[N]）または整数での厳密検証（[E]）である。

## 1. 予想の正確な定式化（roundJ2_notes.md / roundE_notes.md / parts_ja.tex §PK のとおり）

- `(X,σ)=(P²,Π_F)`, `Π_F^{ij}=ε_{ijk}∂_kF`（C³ 上の 2 次 Poisson 構造、Euler の weight 0 で P² に降りる。F は 3 次式）。`L=O(m)` は Poisson 加群（{f,s}=Π(df,ds)）。
- `R=⊕H⁰(O(mk))`、`R_1=` 次数 m の単項式 `y_a=x^a` (N=C(m+2,2) 個)。`S=Sym R_1=C[y_0..y_{N-1}]`, `I=ker(S→R^{(m)})`（2 次式で生成, dim I₂ = C(N+1,2) − C(2m+2,2) = 27 (m=3)）。
- 次数 0 の almost-Poisson な持ち上げ `B₀`: `{y_a,y_b}:=s({x^a,x^b})`, `s:R_{2m}→S_2` は線形な切断（各次数 2m の単項式に y の積 1 通りを割り当てる）。
- 一般の持ち上げ `B=B₀+ε`, `ε∈Hom(Λ²S_1,I₂)`（未知数 = C(N,2)·dim I₂ = 45·27 = **1215**）。`I` は自動的に Poisson イデアルになる（Leibniz と I が I₂ で生成されることから）。
- Poisson 条件: `Jac(B₀+ε)=J₀+L(ε)+J(ε)=0`（S₃ 内の恒等式, 3 つ組 C(10,3)=120 個 × 3 次単項式 220 個。Jacobiator は I₃ に入るので、各次数 3m=9 の単項式クラスの係数和は恒等的に 0（コードで確認）、独立な座標は 220−55=165 個/3つ組、合計 **19800 方程式**）。
- 予想: m≥m₀ で上の方程式に解がある。**本ノートでの「Poisson 拡張が存在する」とはこの方程式（C^N 上の 2 次 Poisson 構造）の可解性**。（§6 で P^{N−1} 上の Poisson 構造という弱い定式化も扱う。）

## 2. 方法

実装: `pkcore.py`（テンソル表現。B[a,b,k]=`{y_a,y_b}` の 2 次単項式 k の係数。`{y_a,m_k}` の演算子 G を持ち、Jacobiator は `Σ_cyc Σ_k B[b,c,k]G[a,k,t]`）。

- **Jacobi 行列は厳密**: Jac は ε の 2 次式なので、基底方向ごとの偏極で Jacobi 行列を厳密に作る（ε のランダムな値で `Jac(B₀+ε)=J₀+Lε+J(ε)` が丸め誤差 0 で成立することを確認 `test_m2.py`）。
- **mod p の厳密線形代数**: `modla.c`（C の密 Gauss–Jordan, p<2³¹, ctypes）+ `modla.py`。L（19800×1215, 疎）の階数、`[L|J₀]` の階数、核を求める。m=3 で 1 秒程度。計算量の見積り: 疎行列でも密行列（19800×1215）でも 2.9e10 回の乗算以下で、素朴な実装で数秒で済む。**1215 未知数は重くない**（以前の保留は LM 数値解法が dict ベースだったため）。
- **完全な 2 次方程式**: Levenberg–Marquardt（正規方程式 JᵀJ+λI, Jacobi 行列は厳密）。`lm.py`, `multistart.py`, 複素版 `restricted_complex.py`。m=3 で 1 反復 5〜30 秒。
- **対称性による縮約（最重要の観察）**: Fermat ではトーラスの weight（単項式 x^a の指数ベクトル）で ε の成分を分解できる。B₀ の成分はすべて shift `ν_k=2e_k−e_i−e_j` (k=0,1,2) の型。最小化点は ‖ε‖² の 99.98% が ν_k 型の成分にあり（`shifts.py`）、ν 型だけに制限した ansatz では未知数は m=2 で 9 個、m=3 で 111 個（各 k で 37 個）、m=4 で 540 個になる。（この ansatz は「F の係数 (a,b,c) について 1 次の universal な持ち上げ」に対応する。）

## 3. mod p の厳密線形代数の結果 [Fp]（`lin_m3.py`, `lin_m3_summary.log`）

p = 32003, 32009, 65521 のすべてで同じ結果:

| m | F | rank L / 未知数 | rank[L|J₀] | 1 次障害 J₀ ∈ im L ? |
|---|---|---|---|---|
| 2 | Fermat | 90 / 90 | 91 | **No**（L は単射） |
| 2 | xyz | 88 / 90 | 88 | Yes |
| 2 | Hesse λ=5 | 90 / 90 | 91 | No |
| 3 | Fermat | 1215 / 1215 | 1216 | **No** |
| 3 | Hesse (x³+y³+z³+5xyz) | 1215 / 1215 | 1216 | No |
| 3 | 尖点 x³−y²z | 1215 / 1215 | 1216 | No |
| 3 | 結節 y²z−x³−x²z | 1215 / 1215 | 1216 | No |
| 3 | xyz（トーリック） | 1215 / 1215 | 1215 | **Yes** |

解釈: 非トーリックでは 1 次障害クラスが非零。L が単射（核 0）なので、1 次の障害理論は「ε は L ε = −J₀−J(ε) で決まるが J₀ ∉ im L」であり、J(ε) の寄与で初めて解が存在しうる。m=2 の Fermat は実際に J(ε) が本質的である。**m=3 では 2 次方程式の可解性は 1 次の線形代数からは決まらない。**

## 4. 完全な 2 次方程式の数値解 [N]

(a) m=2 Fermat（再現）: 6/6 の初期値で残差 1e-14〜1e-19、解は一意で ‖ε‖=12.7279（‖ε‖²=162）。丸めると**整数解**（非零 9 個, 値は ±3, ±6）。整数演算で全 3 つ組・全 3 次単項式に対して Jacobiator = 0 を確認 [E]（`exact_m2_check.py`, `exact_m2_check.log`）。非零成分は `{y0,y1}+=−3(y0y5−y2²)` のような 2×2 小行列式型の 2 次式（スクリプトの出力参照）。
   Hesse 族 F_u=(1−u)xyz+u(x³+y³+z³) を u=0..1 で連続的に追跡（`scan_u.py 2 ...`）しても m=2 では全ての u で残差 ≤1e-13。

(b) m=3、トーリック xyz: LM が 0 に収束（‖R‖≈6e-6 から線形収束、核があるため遅い）。さらに厳密に: 対角 2 次 Poisson 構造 {y_a,y_b}=ω(a,b)y_ay_b が、m=2,3,4 で Jacobiator = 0（全 3 つ組・全単項式, 整数）かつ B_tor−B₀ ∈ I₂（クラス和 0）であることを確認 [E]（`toric_check.py`, `toric_check.log`）。コード全体の検算になっている。

(c) m=3、**Fermat**（`multistart.py`, `ms_m3_fermat.log`）: 初期値スケール 0.1, 0.32, 14.9, 15.3, 33（ガウス乱数）の 5 本すべてで ‖R‖ = 1.656746e+02, ‖ε‖ = 55.259 に収束し、それ以上下がらない。最小点での残差は 120 個の 3 つ組すべてに分布する（最大 29, 最大のものは (x³, y³, yz²) の三つ組）。J₀ の大きさ ‖J₀‖ = 3123.7 に対し 5.3%。
   **複素未知数**（1215 複素変数, 実部/虚部を分けず正則 Jacobi 行列で Gauss–Newton）: 1 本実行（`rc_m3_fermat_all.log`）で同じ ‖R‖ = 165.6746 に収束、最大虚部 2e-9。複素解が実の最小点とは別の所にあるかは、2 本目を打ち切ったので未確認。
(d) m=3、他の 3 次曲線（1 本ずつ, ‖J₀‖ 比）: 尖点 x³−y²z: ‖R_min‖=90.18（‖J₀‖=1326.7）、結節 y²z−x³−x²z: 114.09（1719.7）。いずれも 0 でない。Hesse(λ=5), 円錐+割線は時間切れで未実施。**非トーリックな 3 次曲線ではすべて失敗**というのが現時点のパターン。
(e) Hesse 族を m=3 で u=0→1 と追跡した `scan_u.py 3 ...` は、u=0（トーリック）の解の選び方（解の多様体上の一般点）に依存して追跡が途中で破綻する（u=0.02 で残差 6.7）。時間の都合で打ち切り、**結論には使わない**。

## 5. 縮約した ansatz の解析（原因の手がかり）[N][E]

ν 型 ansatz（m=3, 111 未知数）:
- 実 LM: ‖R_min‖ = 168.7055（3/3 本）, 複素 LM: 12/12 本 同じ値（虚部 ≲1e-10）。全未知数の最小値 165.67 とほぼ同じ。
- **各項 F=x_k³ 単独では解がある**: F=x³ のとき ν₀ 型の 37 未知数の系は解をもつ（`restricted.py 3 x3 nuk0`）。孤立解 a（‖a‖=23.9178, 成分は 9/8 の整数倍）と、Jacobi 行列が特異な解 b（‖b‖=56.285, 成分は 3 の整数倍）が見つかる。**a を 1/8 刻みに丸めて厳密に Jacobiator = 0 を確認 [E]**（`x3_exact.py`, `x3_exact.log`）。つまり m=3 でも解が存在する場合はこの手法が厳密解を出す。
- 失敗するのは 3 つの項（x³, y³, z³）の**同時両立**（交差項 [B_i,B_j]=0）の部分。m=2 では 3 項が両立する（整数解）が、m=3 では ν 型 ansatz の範囲で両立しない（数値的）。
- m=4（540 未知数, Fermat）: 1 本目 ‖R_min‖ = 770.08（‖J₀‖=16217, 4.7%）。解は見つからなかったが、これは ν 型 ansatz に制限した検査であり、m=4 の完全な検査ではない。

## 7. 限界・未確認

- **mod p の厳密な非存在証明は得られていない**。m=3 の「解なし」は数値（LM が同じ最小値に収束）に基づく。2 次方程式の系（1215 変数, 19800 式）を Nullstellensatz/Gröbner 基底で厳密に判定する実装は持っていない（ν 型 111 変数でも密な Macaulay 行列が大きすぎる: 3 次で列 24 万）。ν 型の単独項 (37 変数) の系だけは 3 次の Macaulay で矛盾が出ない（`xl.py`, `run_v0_xl.py`）ことを確認したのみ。
- LM は局所最小に収束しうる。複数の乱数初期値・複素化で同じ点に収束したが、これは大域最小であることの保証ではない。解が孤立で ‖ε‖ が大きい場所にあれば見逃す。m=2 の解（‖ε‖=12.7）や m=3 の F=x³ の解（‖ε‖=23.9）は容易に見つかっているので、見逃しにくいとは思うが、証明ではない。
- 完全な全未知数での検査は m=3 の Fermat のみ複数本。尖点・結節は各 1 本、Hesse の他のパラメータ・m≥4 の完全版は未実施（m=4 の完全版は未知数 7875 個, 3 つ組 455 個で Jacobi 行列が 17GB 規模になるため、疎構造の利用か行列を持たない CG が必要）。
- 1 次障害の mod p 計算は p=32003, 32009, 65521 で行った。複数の素数で同じ結果だが、標数 0 での結果と一致する保証は階数が一致することの確率的議論のみ。
- 切断 s の選び方に依存するのは B₀ のみで、解の存在は選び方に依らない（ε の平行移動）。
- 一般の Sklyanin 型の一族に関して: F が Hesse 束 x³+y³+z³+λxyz のとき Π_F は P² 上の古典的な楕円 Sklyanin（Feigin–Odesskii q_{3,1}(E)）型の Poisson 構造族と一致する、というのは筆者の記憶による（本計算では未確認）。計算した範囲: Fermat (λ=0), 尖点・結節（特異な D）。Hesse λ=5 は 1 次障害のみ（mod p）。
- Poisson 加群の構造は {f,s}=Π(df,ds)（cp2_notes の導出, 一意）を前提にした。
